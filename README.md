# Anza Works

Two separate products live in this repository. Stage 1 develops the public portfolio in portfolio/. The existing private Admin app in admin/ remains untouched for a later stage. Run them on different origins; never copy Admin records into the public site.

## Run the portfolio locally

Requires Python 3, Node.js, and npm:

    npm ci
    npm run build
    npm run dev:portfolio

Open http://localhost:3000. The site is static HTML, CSS and JavaScript generated by portfolio/build.py; there is no server-side database or paid API.

    npm run lint
    npm run typecheck
    npm test
    npm run build

There are no TypeScript source files in Stage 1; typecheck currently runs syntax checks for JavaScript and Python sources. It is not a TypeScript compiler pass.

## Public structure

- / — studio introduction, selected work, services, process, FAQ and contact CTA
- /work/ and /work/<slug>/ — five concept case studies
- /services/, /about/, /process/, /contact/
- /404.html and /error.html

The source project copy and services are in portfolio/data.py; build.py renders the pages and public projects.json. portfolio/media.json maps optional approved project video files. The abstract case-study artwork is a concept presentation, not a screenshot of a delivered client project.

The original creator illustration is in portfolio/public/media/anza-creator.webp. It is an Anza Works concept illustration, not a portrait of the studio owner. The existing typographic AW mark is a fallback. Place verified brand files in portfolio/public/brand/ and update the header/favicon references when supplied; do not treat the fallback as the official logo.

For a case-study film, put optimized MP4 and/or WebM plus a poster under portfolio/public/media/, then add a slug entry in portfolio/media.json, for example:

    {"northline-hotel":{"mp4":"/public/media/northline.mp4","webm":"/public/media/northline.webm","poster":"/public/media/northline.webp"}}

Run npm run build. Video sources attach on interaction, and the player stays in normal HTML. The contact form validates and opens an email draft; it does not submit to a backend. Verify hello@anzaworks.lk before publishing. Testimonials and social links remain hidden until real, approved content exists.

SEO uses the future domain https://anzaworks.lk for canonicals, sitemap and social tags. Update centrally in portfolio/build.py before publishing if the domain changes. The site has not been deployed.

## Admin (Stage 2, unchanged)

The existing offline Admin PWA has local IndexedDB data, domain calculations, encrypted backup/restore and PDF export. It is intentionally independent from the portfolio. Its existing documentation is under docs/; no Admin features were built during Stage 1.
